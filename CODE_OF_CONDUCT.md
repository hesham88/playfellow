# Code of conduct

This project's issues are a place for people who want to build game-playing AI that helps people. In them:

- be respectful and assume good intent; criticise ideas, not people;
- no harassment, hate, threats or sexual content;
- don't share anyone's personal data, API keys or private screenshots;
- don't ask for help with uses the [LICENSE](LICENSE) forbids (Attachment A): military or weapons use, violence, surveillance, cheating against other players, or products for minors.

The maintainer may edit, lock or remove anything that breaks these rules and may block repeat offenders. To report a problem privately, use the contact on the GitHub profile [@hesham88](https://github.com/hesham88).
