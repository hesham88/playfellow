# Security

Please **don't** open a public issue for a security problem. Report it privately through GitHub's "Report a vulnerability" button on this repository (Security tab), with steps to reproduce.

Especially important to us: any way input could reach a window other than the chosen game, any way to bypass the F12 / corner stop, the control-card allow-list or the blocked-window list, and any leak of API keys, personal data or screen content.

**API keys never belong in this repository.** Keys are read from the environment or your operating system's credential store at run time.
